A tiny browser snake game built by an AI coding agent from a single prompt — watch the agent work, then play the game it made. This repository is the entry for make.fun's "The agent builds a game from one prompt" bounty: the agent made a short video showing the prompt, the agent working, and the finished game running, ending with make.fun's referral end card, and the video was posted natively on X.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Play the game

Open `game.html` in any browser. Steer with the arrow keys or WASD, Space to pause, R to restart. Add `?demo=1` to the URL and the agent plays itself.
